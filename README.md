# hxyfront-62009 地毯修复纹样档案 · 报价确认流程

源提示词编号：2

给手工地毯修复工作室使用的档案台前端。针对"口头开工、追加破损/换色说不清、结算争吵"的问题，档案台内置报价确认流程：

- **接单建档即出估价**：按修复面积（元/m²）、破损处（元/处）、补线色号（元/绞）算出分项金额，生成 V1 估价单，状态"待确认"。
- **师傅发起变更**：追加破损或更换补线色号后自动生成带版本号的新估价单，变更原因记录在版本上；旧版本全部标记"已失效"。
- **分项状态流转**：已完成工序对应的分项金额锁定保留（已完成·保留）；上一版已确认的分项沿用；未开始的增项停在"待确认"；未开工的补线项在换色时被新色号替换。
- **客户确认才能施工**：当前版本待确认时工序全部暂停，客户同意当前版本后才能开始/推进工序。
- **版本留痕**：重开页面可看到每一版的金额、变更原因、生成/确认时间与确认状态；数据保存在本机浏览器 localStorage。
